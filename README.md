# Шифр Цезаря

**Софья Колесникова**

Возможности:
1. Зашифровать файл
2. Расшифровать файл с ключом
3. Взломать перебором ключей

Ограничения: 
Программа корректно распознаёт только 42 символа, указанных в классе MainApp.
При шифровании исходный текст приводится к нижнему регистру, при расшифровке текст записывается в файл в нижнем регистре.
